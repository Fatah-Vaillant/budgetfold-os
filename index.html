      Sécurité et appareils

      Verrou de l'app, sauvegarde chiffrée, passage sur un autre appareil. Toujours sans serveur.

      Verrou de l'app

      Le code empêche d'ouvrir l'app sur cet appareil ; il est haché, jamais stocké en clair. Il demande à nouveau le code après une minute en arrière-plan.

      Sauvegarde chiffrée et transfert

      Pour restaurer : menu › Importer une sauvegarde, puis le mot de passe. Sans le mot de passe, personne (pas même toi) ne peut relire le fichier.

      Scanne ce code avec l'appareil photo de l'autre téléphone : BudgetFold s'ouvre et demande le mot de passe. Les photos ne passent pas par le QR code : utilise la sauvegarde chiffrée pour elles.

      Confidentialité

      Ce que BudgetFold garde, où, et comment tout effacer.

      Ce qui est stocké

      • Ton budget, tes opérations, tes projets et tes réglages, dans le stockage local de ce navigateur (clé budgetfold-os:v4 ; les clés des anciennes versions sont gardées pour ne rien perdre).
      • Les photos et PDF de tes justificatifs, dans la base locale du navigateur (IndexedDB budgetfold-photos).
      • Les fichiers de l'app, en cache, pour qu'elle marche hors ligne.

      Où

      Uniquement sur cet appareil. Aucun compte, aucun serveur BudgetFold, aucun traceur, aucune publicité. Tes exports restent des fichiers que toi seul déplaces.

      Ce qui est chargé en ligne

      La police Inter (Google Fonts), les icônes (Lucide, unpkg), et à la demande le moteur de lecture des tickets (Tesseract), le lecteur de PDF (pdf.js) et le générateur de QR code (jsdelivr). Comme pour tout site, ces services voient ton adresse IP au téléchargement ; aucune donnée de ton budget ne leur est envoyée.

      Tes droits (RGPD)

      Tes données ne quittent pas ton appareil : tu en gardes le contrôle total. Exporte-les quand tu veux (menu › Exporter), et efface tout d'un geste ci-dessous. Le verrou par code protège l'accès à l'app, mais une personne qui maîtrise les outils du navigateur sur ton appareil déverrouillé pourrait lire les données : garde ton téléphone verrouillé.
